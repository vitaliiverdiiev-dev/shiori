# Shiori - M03.4.1: Focused Refactoring & M03 Closure

## Goal

Fix the confirmed problems and settle the open decisions from the M03.4 audit (HEAD `c9b20f0`), without a general refactor.

## Decisions

C1 and the D1 confirmation were revised in M03.4.2 (`docs/tasks/M03.4.2-final-verification.md`).

| Finding | Decision                                                                                                                                                                                                                                                                                                                                     |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C1      | The practice field has `maxLength` 32; the reducer ignores longer input and refuses a longer answer; finalized answers are never truncated. Oversized restored input restores as an empty field; a restored attempt with an oversized answer invalidates the round.                                                                          |
| C2      | The batch stays one transaction. A 400 names every invalid entry as `invalidIndexes` (policy failures and Zod issues at `attempts[i]`), or omits it when the request is invalid as a whole. The client validates the indexes, moves only those entries to `invalid` and sends the rest; without usable indexes the batch goes to `rejected`. |
| D1      | Refused results stay on the device until the user acts: **Send again** (only `rejected`, including batches refused by earlier versions) and **Remove…** with a confirmation popover. Pending results are never touched; nothing is discarded automatically.                                                                                  |
| D2      | **Start new round** finalizes a wrong answer awaiting correction as `incorrect`, `corrected: false`, keeping `hintUsed`, before replacing the round. **Leave**/**Resume** finalize nothing. No unload requests: closing the tab while correcting can leave that question unrecorded (accepted).                                              |
| C3      | Table definitions (`persistence/schemas/*.schema.ts`) may not re-export (`export … from`, `export *`) or import `#infrastructure/database/*`, `pg` or `drizzle-orm/node-postgres`. Fixtures cover both and the legitimate foreign key.                                                                                                       |
| C4, D3  | Stale statements in `docs/03-architecture.md` corrected, superseded M03.3 decisions marked, M03.3.4 record added. The statistics column “Last practised” is now “Last saved” (server receipt time); no migration, no client timestamp.                                                                                                       |

Out of scope: catalog, Kana ids, reducer redesign, TanStack Query setup, idempotency model, authentication, selection grids, footer, tabs, practice states, design tokens, new features.
