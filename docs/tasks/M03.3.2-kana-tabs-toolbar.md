# Shiori — M03.3.2: Kana Page Tabs & Practice Toolbar Polish

## Goal

Split each Kana page into **Practice** and **Statistics** tabs and make the selection toolbar compact, without changing data, API, catalog or practice behaviour.

## Decisions

| Topic      | Decision                                                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tabs       | Official shadcn Base UI `Tabs`, `line` variant, inside `KanaSelection`; local UI state defaulting to Practice; no new routes.                                              |
| State      | Both panels `keepMounted`; selection, question count and rounds keep their existing session storage; one progress query and one attempt sync above the tabs.               |
| Toolbar    | One wrapping row: left (count, Questions, description), right (Select all, Clear, Resume/Start). `PracticeLauncher` gains two optional slot props for the selection parts. |
| Sticky     | Header always; toolbar only from `md`. Scroll margin 5 rem on phones, 12 rem from `md`.                                                                                    |
| Statistics | Concise summary line, table shown without a disclosure, one short footnote; existing columns and aggregation unchanged.                                                    |

Out of scope: backend, catalog, practice reducer, transitions, hints, statistics definitions, sidebar, theme, other pages.
