# Shiori - M03.3.4: Contextual Section Information

Record written in M03.4.1; the work was requested in conversation and committed in `c9b20f0` without a task document.

## Goal

Stop showing the Kana section descriptions permanently and offer them on demand, without changing data, API, catalog or practice behaviour.

## Decisions

| Topic     | Decision                                                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Component | Official shadcn Base UI `Popover` (`shared/ui/primitives/popover`, unmodified) behind a muted Info icon `Button` (`About <section>`) beside each title.       |
| Content   | Section title and description from `@shiori/kana`; nothing duplicated in the component.                                                                       |
| Behaviour | Hover with a 300 ms delay, click or tap toggles, Enter/Space from the keyboard, Escape closes and returns focus. The trigger sits outside the checkbox label. |
| Touch     | `pointer-coarse:size-10` on the icon button.                                                                                                                  |
| Ownership | Composed in `domain/kana/ui/kana-section.tsx`; one use, so no shared composite.                                                                               |

Current behaviour: `docs/03-architecture.md` → “Kana progress (M03.3)” → “Section information (M03.3.4)”.
