## Guardrails

- Strong TS (no `any`, non-null assertion, unsafe assertions); follow slice `index.ts`, import/order rules, lean React files, frontend model/helpers/store conventions.
- TDD with observable behavior and risk-targeted integration tests. No test inflation, blanket `TODO`s or autogenerated comments.
- Database migration must be generated and reviewed, not schema push; `pnpm dev` and `pnpm db:migrate` must remain idempotent.
- Do not add speculative tables, wrappers, middleware, decorators, providers, auth APIs or UI to prepare future milestones.
- Preserve `/api/health` and `/api/ready` externally; protect actual private APIs on backend.
- Do not claim invitation atomicity, restriction of admin endpoints or runtime browser verification without executing tests that demonstrate them.
