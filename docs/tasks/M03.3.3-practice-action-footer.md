# Shiori — M03.3.3: Persistent Practice Action Footer

## Goal

Move the Practice controls from the top toolbar into a footer that stays at the bottom of the viewport while the Practice tab is active.

## Decisions

| Topic       | Decision                                                                                                                                                                  |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Grouping    | Left: `n selected` · Select all · Clear. Right: Questions [input] · Resume/Start. Phones: the same two groups as two rows.                                                |
| Placement   | Pure CSS: last element of the Practice panel, `sticky bottom-0` + `mt-auto` in the existing full-height flex chain. No Portal, JavaScript or nested scroll container.     |
| Width       | Controls aligned with the content column; background and border span the area beside the sidebar via a clipped pseudo-element (`overflow-x-clip` on `SidebarInset`).      |
| Spacing     | `--app-content-bottom` lets the footer cancel the column's bottom padding; the footer adds the safe-area inset. Scroll margins keep focus clear of the header and footer. |
| Statistics  | The footer is part of the Practice panel, so it is hidden there with no reserved space.                                                                                   |
| Description | The question-count description stays as the input's accessible description; only validation errors are visible.                                                           |
