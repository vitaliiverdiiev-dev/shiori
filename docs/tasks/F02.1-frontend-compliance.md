# F02.1 — Frontend Architecture Compliance & Simplification

Follows F02 (startup, theme & branding). A focused cleanup against KataKit 0.4.2 (component ownership, CVA, simplicity, accessibility), not a redesign.

## Scope

1. **Main component contract enforcement:** extend the existing ESLint `no-restricted-syntax` contract to shared UI composites, `ui/` segment components and app components. Keep the exceptions for generated shadcn primitives, tests, stories, helpers, hooks, config and variant files. Add positive and negative fixtures for the new locations.
2. **`shared/theme` organisation:** `model/` (types, constants), `helpers/` (pure operations and the inline script), `hooks/` (context, `useTheme`, shortcut hook), `ui/` (provider, control, menu) and `tests/` by the deterministic placement rule. `index.ts` is the module's only public API. No fake main component and no nested index files.
3. **Theme simplification:** compare against the official shadcn Vite theme approach. Replace the `Function.toString()` serialisation with an explicit inline script. Measure the lazy theme menu against an eager one, and keep lazy loading only if it pays for itself. Remove handlers, state and props that add no value.
4. **D shortcut:** `D` outside editable controls switches between Light and Dark (from System, to the opposite of the resolved theme). Ignore editable targets, menus and dialogs, IME composition, unassigned modifiers and key repeat. WCAG 2.1.4: the user can turn it off, and the setting persists.
5. **Logo:** apply the contract; move size variants to CVA in `ui/logo-variants.ts`; extract `LogoMark` for the duplicated mark markup. Keep the API and accessibility behaviour.
6. **Styling ownership:** CVA only for prop-driven appearance variants touched by this cleanup. No redesign.

## Testing

Theme persistence and system changes, initial HTML theme, startup shell replacement, selector keyboard behaviour, D shortcut and its setting, Logo variants and names, provider behaviour, and the existing auth, lazy-route, recovery and cache-isolation suites. Run lint, typecheck, format, tests, web build and Storybook build. Record bundle sizes before and after.

## Out of scope

Full redesign, learner/admin navigation, form refactoring, React Compiler, Axios→fetch, new shared packages or layers, backend changes, unrelated dependency upgrades.

## Rules

Work on `main`, no branches. Do not commit or push. Stop after implementation and verification.
